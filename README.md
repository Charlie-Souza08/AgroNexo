# AgroNexo

## Descrição do Projeto

O **AgroNexo – Gestão de Fazenda** é um projeto de banco de dados desenvolvido para auxiliar no gerenciamento das atividades e recursos relacionados à administração de uma propriedade rural.

A solução terá como finalidade organizar informações sobre propriedades, talhões, culturas, funcionários, máquinas, insumos, atividades agrícolas e produção, permitindo o registro e acompanhamento das operações realizadas na fazenda.

## Objetivo da Solução

O objetivo do projeto é desenvolver uma solução de banco de dados utilizando a linguagem SQL, com desenvolvimento e gerenciamento realizados por meio do DBeaver, para armazenar, organizar e consultar informações relacionadas à gestão agrícola.

A solução deverá possibilitar o controle das principais atividades da fazenda, permitindo registrar informações como:

Propriedades e áreas de cultivo;
Talhões e culturas plantadas;
Funcionários e responsáveis pelas atividades;
Máquinas e equipamentos agrícolas;
Insumos utilizados, como sementes, fertilizantes e defensivos;
Atividades realizadas no campo;
Datas de plantio, aplicação e colheita;
Quantidade de insumos utilizados;
Produção e produtividade das culturas;
Custos relacionados às atividades agrícolas;
Histórico das operações realizadas.

Com isso, o AgroNexo poderá contribuir para uma gestão mais organizada e eficiente da propriedade rural, permitindo o acompanhamento das atividades agrícolas, o controle dos recursos utilizados e a consulta ao histórico de produção.

Tecnologias Utilizadas

O projeto será desenvolvido utilizando:

SQL – linguagem utilizada para criação, manipulação e consulta dos dados;
DBeaver – ferramenta utilizada para desenvolvimento, gerenciamento e execução dos comandos SQL;
Sistema Gerenciador de Banco de Dados (SGBD) – responsável pelo armazenamento e gerenciamento das informações da aplicação.

A proposta busca aplicar, na prática, os principais conceitos estudados na disciplina de Linguagem SQL, incluindo criação de tabelas, relacionamentos entre entidades, inserção e atualização de dados, consultas, filtros, ordenação, agrupamentos e utilização de chaves primárias e estrangeiras.
